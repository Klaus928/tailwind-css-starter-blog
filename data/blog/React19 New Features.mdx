## 新特性

- `<Activity />` 组件
- useEffectEvent
- cacheSignal 缓存信号
- Performance Tracks

### Acticity 组件

可以使用Activity 去隐藏或恢复组件的状态，在条件渲染情况下非常有用

## React DOM 新特性

- SSR 部分预渲染

## 值得注意的变动

- SSR 中 Suspense 批处理
- eslint-plugin-react-hook v6
- 更新默认useId前缀
